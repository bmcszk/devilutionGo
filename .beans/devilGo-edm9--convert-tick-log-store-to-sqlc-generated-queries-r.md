# Convert tick-log store to sqlc-generated queries (remove the hand-written-SQL exception)

## Goal

Owner directive (verbatim): "Are you using sqlc for db layer? It should be used
everywhere." The tick-log column family (`tick_commands`, `tick_events`,
`tick_checksums`, `tick_snapshots`) is the last data access in
`internal/persist` that hand-writes SQL strings, under a stated exception in
`ticklog_store.go`. Convert it to sqlc like the rest of the store and delete the
exception.

## Research

- Root `sqlc.yaml` lists only `internal/persist/schema.sql` and
  `internal/persist/schema_v2.sql` under `schema`; `schema_v3.sql` (the tick-log
  DDL) is missing — that is why sqlc never saw these tables.
- Existing queries live in `internal/persist/queries/store.sql`; generated code
  goes to `internal/persist/sqlc` (package `sqlc`), marker `Code generated by
  sqlc. DO NOT EDIT.`
- `SQLiteStore` already holds `queries *sqlc.Queries` and uses
  `s.queries.WithTx(tx)` for transactions (`DeleteHero`), so a tick batch gets
  the same seam.
- Driver is `modernc.org/sqlite`; sqlc supports it natively (no cgo).
- Gate: `just sqlc-check` = `sqlc generate` + `git diff --exit-code --
  internal/persist/sqlc` + `scripts/check-no-raw-sql.sh`; sqlc v1.31.1 installed.
- Hand-written statements in scope (`ticklog_store.go`): 4 INSERTs + 4 SELECTs.
  No DELETE/purge of tick rows exists anywhere (grep: only migrate tests read
  the table names, and `ticklog_test.go` inserts NULL rows on purpose to prove
  the NOT NULL constraints).
- Infrastructure stays on the raw handle by design: `PRAGMA user_version`
  reads/writes and migration DDL execution (`migrate.go`).

## Scope

- `sqlc.yaml` + `internal/persist/schema_v3.sql` (schema list only).
- `internal/persist/queries/ticklog.sql` (new): every tick-log data statement.
- `internal/persist/sqlc/*` (regenerated).
- `internal/persist/ticklog_store.go`: thin adapter over `sqlc.Queries`;
  exception paragraph removed.
- `internal/persist/ticklog_test.go`: mechanical renames only.
- `docs/go-libraries.md`: sqlc row (catalog had none).
