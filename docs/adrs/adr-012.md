# 012. Natural dependency order, Phase 0 first

Date: 2026-10-16
Status: Accepted

## Context

Artificial ordering (milestone-first or feature-first) either blocks ready work or invites out-of-order landings.

## Decision

Epics execute in natural dependency order. Phase 0 (scaffold, engine skeleton, CI gates) lands first. Every blocked_by edge in the tracker is real; workers only claim todo beans with zero open blockers.

## Consequences

Dispatch order follows the tracker. Bean readiness is visible in the ledger status.
