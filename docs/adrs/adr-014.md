# 014. One migration tool: devilutionGo-migrate

Date: 2026-11-03
Status: Proposed

## Context

Accepted law already requires three migrations: MPQ extraction to assets (ADR-005), legacy save import to SQLite (ADR-003, planned binary devilutionGo-import), and diablo.ini carry-over (ADR-004). Separate tools would duplicate MPQ/decode logic and drift.

## Decision

One CLI, devilutionGo-migrate, with subcommands: assets (MPQ to assets dir, CSV registries + YAML manifests per ADR-013), saves (legacy .sv/.sp to per-hero .db plus global.db; this subcommand is the ADR-003 importer, which keeps its semantics - the standalone devilutionGo-import name is superseded), settings (diablo.ini passthrough verify per ADR-004). Idempotent, dry-run mode, checksum verification, real-data tested like all import paths (ADR-010).

## Consequences

One entry point, one verification suite, no duplicated decode logic; CI embeds exactly the tree that migrate produces (ADR-005).
