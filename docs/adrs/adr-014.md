# 014. One migration tool

Date: 2026-11-03
Status: Accepted (2026-11-03)

## Context

Accepted ADRs already need three migrations: MPQ contents to an assets folder when building (ADR-005), old saves to SQLite (ADR-003), and diablo.ini carry-over (ADR-004). Three separate tools would repeat the MPQ decode code and grow apart over time.

## Decision

One command line tool named devilutionGo-migrate with three subcommands. `assets` copies MPQ contents into the assets folder and writes the CSV tables and YAML lists from ADR-013. `saves` reads old .sv and .sp saves and writes the per-hero .db files plus global.db; this subcommand is the ADR-003 importer, so the separate devilutionGo-import name goes away. `settings` checks and carries over diablo.ini (ADR-004). The tool gives the same result when run twice, supports a dry-run flag, verifies checksums, and is tested against small synthetic fixtures under internal/testdata (zero-dependency parity tests; retail files are environment amendments, never test dependencies).

## Consequences

One tool to learn and one set of shared parsing code. The build embeds exactly the files the tool writes (ADR-005), so what CI packages matches what users migrate with.
