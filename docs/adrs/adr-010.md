# 010. TDD and parity gates are blocking

Date: 2026-10-16
Status: Accepted

## Context

1:1 fidelity (ADR-002) needs mechanical enforcement, not review trust.

## Decision

Every bean is test-first. CI runs six blocking parity gates (just ci): format compatibility, save roundtrip, light-table goldens, RNG sequences, sprite decode goldens, full-frame parity at 1x and 2x. A failing gate blocks merge. No golden fixture means the feature is not done.

## Consequences

Fidelity is a build property. Gate failures name the exact mismatched artifact.
