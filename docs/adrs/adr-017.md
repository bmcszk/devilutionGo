# 017. Runs without a window; graphics code stays separate

Date: 2026-11-03
Status: Accepted (2026-11-03)

## Context

CI, servers, and automated agents must run the game without a screen. Graphics and sound should stay swappable later. ADR-008 already puts that code in engine/ and provides the headless binary.

## Decision

One program, three run modes. `sim` runs the simulation with no window and prints state checksums. `server` is the same, prepared to host future multiplayer. `client` draws with Ebiten (ADR-001). The code in engine/ only reads game state and sends input; it never writes game state. When engine/ has real drawing, tests can run the client inside Ebitengine 2.10's headless guest mode and compare the captured frames against golden images.

## Consequences

CI and agents can verify the whole game without a GPU or screen. Swapping the graphics or sound library touches engine/ only.
