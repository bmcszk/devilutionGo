# 017. Headless-first run modes; presentation strictly separable

Date: 2026-11-03
Status: Proposed

## Context

The simulation must run without a window (CI, servers, agent-driven verification), and rendering/audio must stay swappable (catalog already routes those libs; ADR-008 puts them in engine/).

## Decision

One binary, three run modes: sim (headless kernel + checksums, zero engine imports), server (headless host for future MP), client (Ebiten presentation per ADR-001). engine/ code subscribes to kernel events and never mutates simulation state. Golden rendering tests run via Ebitengine 2.10 Application Virtualization (headless guest, host-driven ticks and captured frames), added once engine/ has draw paths worth golden-testing.

## Consequences

CI can play and verify the game without a GPU or window; a future engine or audio stack swap touches engine/ only, never game/.
