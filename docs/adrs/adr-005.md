# 005. MPQ assets extracted at build time

Date: 2026-10-16
Status: Accepted

## Context

devilutionX reads MPQ archives at runtime. Go has no mature pure-Go MPQ stack, and compression gains from MPQ are marginal (PKWARE-imploded data compresses about the same as PNG/WebP).

## Decision

v1 extracts MPQ contents to loose assets at build time and embeds them (go:embed). The runtime reads a manifest, never MPQ files. A runtime MPQ reader is a deferred optional post-1.0 feature bean, not cut.

## Consequences

Zero-install retail-CD support waits for the optional runtime reader bean. Build pipeline owns extraction, codec gaps (PKWARE/ADPCM) are explicit deliverables.
