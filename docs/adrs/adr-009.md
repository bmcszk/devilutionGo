# 009. Library choices pinned in a catalog

Date: 2026-10-16
Status: Accepted

## Context

Workers picking libraries per task would produce duplicates and CGO leaks. The catalog in docs/go-libraries.md evaluated options per area.

## Decision

docs/go-libraries.md is the canonical catalog. Pinned picks: donburi (ECS), s0rg/grid and SolarLune/paths (grid and A*), leonelquinteros/gotext (i18n), quasilyte/ebitengine-input, yohamta/donburi containers, modernc.org/sqlite (pure-Go driver), suprsokr/go-mpq for build-time extraction with PKWARE/ADPCM filled by our port. Beans name their libraries in a Libraries section with module path and purpose. A worker may not substitute a library; changes go through a milestone decision.

## Consequences

Beans are self-contained contracts. Substitutions fail review. New needs amend the catalog first.
