# 001. Go, Ebitengine, SQLite as the stack

Date: 2026-10-16
Status: Accepted

## Context

devilutionX is C++ (Diablo 1 + Hellfire, ~134k LOC in Source/). The port targets Go 1.27. The engine must be reusable for other projects, not just Diablo.

## Decision

Port to Go 1.27 with Ebitengine v2 for rendering and input. Store saves in SQLite. Keep the whole build pure Go: no CGO anywhere, including drivers and codecs.

## Consequences

Go code reads differently from C++ but must behave identically. Library choices obey the pure-Go rule (see ADR-009).
