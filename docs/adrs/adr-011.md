# 011. All code changes via pi sub-agents; orchestrator never codes

Date: 2026-10-16
Status: Accepted

## Context

One writer prevents tracker conflicts. The orchestrator holds the ledger and the review loop; workers hold the code.

## Decision

Every coding bean runs through a pi RPC sub-agent with a per-bean contract: read the bean body, implement, keep tests green, report proof of work on the bean. The orchestrator does docs, beans, and review only, never direct code edits. Batch size is one epic. Bean bodies must be complete contracts (IMPL NOTES, skills, libraries, dependencies) before dispatch.

## Consequences

Bean quality gates worker quality. The single-writer rule keeps .beans/ and the repo consistent.
