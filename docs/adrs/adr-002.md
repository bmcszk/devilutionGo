# 002. Fidelity mandate: 1:1 port

Date: 2026-10-16
Status: Accepted

## Context

The project's purpose is a faithful port. Past ports drift because each deviation looks reasonable in isolation.

## Decision

Identical algorithms, constants, formulas, RNG behavior, data values, and network packets. Rendering is pixel-identical. Saves stay byte-compatible through the importer (ADR-003). Any deviation needs a recorded decision (an ADR or a bean note). No recorded decision means the deviation is a bug.

## Consequences

Parity is testable and blocks merges. Porting takes longer than a rewrite but the result is trustworthy.
