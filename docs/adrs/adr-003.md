# 003. SQLite-only live saves with one-time importer

Date: 2026-10-16
Status: Accepted

## Context

devilutionX saves are binary .sv/.sp files. The port needs a Go-native store, but existing saves and byte-level compatibility matter to users.

## Decision

SQLite is the only live save format. One hero = one .db file, mirroring the per-hero .sv model. A separate global.db holds stash and metagame state. A one-time CLI tool (devilutionGo-import old.sv) converts legacy saves and proves byte-compat. No dual-format live writes.

## Consequences

No code path writes .sv. Import correctness is tested against real saves. Settings are NOT in SQLite (see ADR-004).
