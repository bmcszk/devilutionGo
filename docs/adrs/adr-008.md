# 008. Three-layer DDD layout; Appendix E superseded

Date: 2026-10-16
Status: Accepted

## Context

Requirements.md Appendix E proposed a 14-package tree. AGENTS.md later defined a three-layer structure. Beans cited both, which confused workers.

## Decision

AGENTS.md three-layer layout governs: internal/{engine,game,diablo} plus cmd/devilutionGo and cmd/devilutionGo-headless. engine holds reusable project-agnostic code, game holds shared game shell, diablo holds Diablo-specific rules. Every bean that cited Appendix E carries a LAYOUT MAP note with the mapping (world/gameplay to diablo, entity to engine/ecs, render to engine/render, ui to game/ui, net to engine/net+diablo/net, assets to engine/asset+diablo/assets, persist to engine/save+diablo/save, input to engine/input, platform to engine/config, demo to engine).

## Consequences

Bean bodies stay authoritative through their LAYOUT MAP notes. requirements.md Appendix E is historical.
