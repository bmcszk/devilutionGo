# 004. Settings stay diablo.ini, not SQLite

Date: 2026-10-16
Status: Accepted

## Context

devilutionX reads/writes diablo.ini through its own INI codec (Source/utils/ini.cpp). Users copy settings between installs.

## Decision

Settings stay in diablo.ini at the same pref path (~/.local/share/diasurgical/devilution/, portable.ini supported). A Go INI codec ports ini.cpp semantics: sections, keys, and comments preserved. The file is byte-compatible in both directions. global.db never stores settings.

## Consequences

A user can swap diablo.ini between devilutionX and devilutionGo. The global DB stays stash/metagame only.
