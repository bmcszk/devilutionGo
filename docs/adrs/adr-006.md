# 006. Lua deferred, hooks stubbed now

Date: 2026-10-16
Status: Accepted

## Context

devilutionX ships a Lua 1.6+ event API used by 166+ mods. Pure-Go constraint rules out C-binding Lua.

## Decision

Lua support is deferred post-1.0 and will use gopher-lua (pure Go). Phase 0 stubs the LuaEvent hook points in the engine with no VM attached, so enabling later is drop-in.

## Consequences

Mods wait for post-1.0. The hook seams exist from the start, so enablement does not restructure the engine.
