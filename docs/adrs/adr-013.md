# 013. Save and asset compatibility through importers, not dual formats

Date: 2026-10-16
Status: Accepted

## Context

Byte compatibility with devilutionX assets and saves is required, but live dual-format writes double the failure surface.

## Decision

Compatibility is a one-way door: importers convert legacy inputs (saves via ADR-003, MPQ via ADR-005) once at the boundary. After import, the port reads and writes only its native formats. The importer for saves doubles as the byte-compat proof.

## Consequences

One code path per format at runtime. Legacy files remain readable through the import tools only.
