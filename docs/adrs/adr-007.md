# 007. 640x480 logical world, integer scaling

Date: 2026-10-16
Status: Accepted

## Context

devilutionX renders at dynamic gnScreenWidth/Height with zoom, in any window size. The port needs deterministic parity targets.

## Decision

The Go port renders the world to a fixed 640x480 logical surface, integer-scaled to any window (nearest filter). The parity harness produces goldens at 1x (640x480) and 2x (1280x960).

## Consequences

Parity frames are deterministic and comparable. Window sizes beyond integer scale letterbox. High-DPI stays easy to add later.
